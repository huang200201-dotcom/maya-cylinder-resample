# 使用说明

适用版本：Windows / Maya 2024，插件 0.3.2。

## 安装

从仓库 [Releases](https://github.com/huang200201-dotcom/maya-cylinder-resample/releases/latest) 下载发布 ZIP，完整解压后将 `install.py` 拖入 Maya 三维视图。文件会复制到当前 Maya 用户脚本目录，工具会打开，并在 `CylinderTools` 工具架添加 `CR` 按钮。无需安装其他 Python 库。

从旧版升级前先保留或取消预览。拖入新版安装入口即可升级；不会强制卸载仍参与撤销历史的旧网格创建命令。安装后可将 `check_in_maya.py` 拖入 Maya 运行兼容自检，它只创建/删除临时对象并恢复选择。

## 基本流程

1. 切换到边模式，选择一条完整圆周边环；通常双击圆周方向的边即可。
2. 点击“分析选中边环”，需要时使用“选中处理范围”检查面。
3. 设置目标圆周段数和轮廓模式，点击“生成 / 更新预览”。
4. 使用“查看原模型”比较结果。
5. 点击“保留结果副本”或“取消预览”。

原模型的几何和 UV 不被覆盖。关闭窗口会取消尚未确认的预览。“保留时并排放置”默认开启，结果沿世界 X 方向移动到原模型旁边；关闭它则保留原位置。

分析区显示受保护列与最低段数。预览区的“最宽 / 最窄边长”比值越接近 1，边长越一致。更改参数后需要重新生成预览；分析后修改原模型几何或 UV，需要重新分析。

## 轮廓模式

**保留原轮廓**：增段固定所有旧角点，依据所选圈实际边长分配新增段数，并分散余数。规则 24 段增到 36 段会交错拆分旧边，不再让新增段集中在一侧。减段采用弧长采样近似原轮廓；同段数保留原点。

**均匀重采样**：按所选圈折线弧长重新分配顶点，适合任意目标段数或原分布不均匀的情况。同段数也可重排。未受保护的旧角点可能移动或略过；跨越旧角点的新直线边会略短于原折线弧长，因此不保证精确等长。

**圆形拟合**：每个截面分别拟合圆，按所选圈角跨度分配。截面应近似圆形且近似共面；明显变形、椭圆及非共面截面应选择其他模式。拟合在对象空间执行，保留原世界变换，因此非均匀缩放后的世界轮廓可呈椭圆。

三种模式都保持截面层数，不修改长度方向的段数。其他圈沿原顶点列对应关系同步采样；其他截面的边长/角度分布不同时，结果也可能不均匀。原轮廓和均匀模式使用世界空间边长，圆形模式的边长统计使用对象空间。

固定全部旧角点和任意段数等距通常不能同时实现。例如 24→36 保留全部旧点后，必然包含未拆分边与二分边两种宽度。想让间距更一致，请选“均匀重采样”；需要更圆的截面，选“圆形拟合”。

## UV 与结构限制

UV 从原面角插值，固定接缝列，并保留岛的布局坐标，不重新展开或打包。接缝两侧独立，即使坐标相同也不会自动焊接。工具保留全部 UV 集和当前 UV 集。

保留布局不等于逐像素保持贴图。减段损失表达精度，端盖的内部三角划分变化及表面位置变化也可能改变贴图表现。UV 接缝、材质边界和硬边约束会限制均匀程度；目标段数不足时应增加段数。关闭“保留 UV”会生成没有 UV 的结果。

支持连续四边形环带，各圈点数一致，包括整圈倒角、台阶、凹槽、收口与变径；支持开放端口、单个 N-gon 及单中心点三角扇端盖。不支持孔洞、侧向分支、杂乱三角面、复杂端盖、非流形、面朝向不一致、闭合环面或处理区的零长度边/零面积面。

锁定法线按软硬边重新计算；顶点色、蒙皮、动画、变形器和自定义属性不转移。有绑定的模型会生成当前姿态的静态副本。工具处理整个连通圆柱，不只改单独一圈后生成过渡拓扑。

## 更新

点击“检查 GitHub 更新”，确认正式新版本后安装。更新前保留或取消预览。更新来自固定公开仓库的 GitHub Releases，不需要登录，不直接读取开发分支代码。下载与安装完成后会重新打开工具，需要重新分析模型。

下载会检查大小、SHA-256 和文件清单；旧代码先备份，切换失败会尝试回滚。网络中断或 GitHub 限流时保留当前版本，稍后重试，也可从 Releases 下载 ZIP 手动拖入安装。

0.3.1 若出现 `name '__file__' is not defined`，并提示 `maya.cmds` 缺少 `crCreateMesh_...` 命令，请检查更新至 0.3.2。无法在窗口内更新时，下载新版发布包，完整解压后拖入 `install.py` 重新安装。无需手动修改或删除命令缓存。

更新不会修改已经保留的普通网格，不主动清空撤销历史。旧网格创建命令保留在版本化缓存中，以免 Undo 引用失效。不要在 Maya 运行时手动删这些文件。

## 示例与验证

- `processed_24.obj`：带倒角、台阶和凹槽的 24 段模型。
- `comparison_24_16_36.obj`：24、16、36 段并排对比。
- `spacing_modes_24_36.obj`：原 24 段、原轮廓 36 段、均匀 36 段、圆形 36 段；可用线框和 UV 编辑器检查。

纯计算及模拟测试不替代 Maya 实机测试。当前机器导入 Autodesk DLL 时发生 `WinError 1114`，实际场景、界面、撤销与热更新端到端流程尚未完成实机验证。请先使用副本场景和示例模型测试。

## 卸载

删除 `CylinderTools` 工具架的 `CR` 按钮。退出 Maya 后删除用户脚本目录中的 `cylinder_resample` 文件夹。安装器/更新器创建的备份与命令缓存可在退出 Maya 后清理；已经保留的结果是普通网格，不依赖工具。
